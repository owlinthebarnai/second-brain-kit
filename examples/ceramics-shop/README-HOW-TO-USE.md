# How to use this second brain (for you, not for Claude)

## Check it loads
Open Claude Code in this folder and run /context. CLAUDE.md must appear under memory files.

## The loop
- START: "Read projects/now.md and tell me where I stopped."
- DURING: do the work. Keep rough notes anywhere: bullets, voice dictation, photos.
- END (2 min): "Close this session" + paste your raw notes. Claude files everything.
- MONTHLY: "Do the monthly review" on the first Sunday of the month.

## Skills: say it in plain words
| Group | Playbooks | Say something like |
|---|---|---|
| rhythm | session-close, review | "Close this session" + notes / "Do the monthly review" |
| orders | new-order, restock-check | "New order from the cafe: 24 mugs" / "What needs restocking?" |
| content | product-listing | "Write the listing for the planter" |

## Rules of thumb
- If it matters, it goes in a file. Chat instructions vanish after compaction.
- Never put customer addresses, emails or API keys in any file.
- CLAUDE.md stays under 150 lines. Rules for one folder go in .claude/rules/.
- When something breaks, it goes into "Common pitfalls" in CLAUDE.md. Session close does this for you.
