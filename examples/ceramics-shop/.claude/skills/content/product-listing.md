Goal: a listing that is accurate first and warm second.

## Gather (read, do not guess)
1. Read the product file and .claude/rules/publishing.md.
2. Ask only for what is missing: photos taken, anything special about this batch.

## Do
3. Run the orders skill's restock-check for this product first.
4. Draft: one-line hook, 2-3 lines on how it is made, specs as bullets, price and stock from the product file.

## File it
- Save in drafts/YYYY-MM-DD-product-listing.md.
- Show it for approval.

## Never
- Invent specs, prices or stock. Unknown = "unknown".
