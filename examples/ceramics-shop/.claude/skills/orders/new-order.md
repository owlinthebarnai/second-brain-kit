Goal: every order or quote is priced by the rules and tracked to delivery.

## Gather (read, do not guess)
1. Read the product files involved, the customer file (if any) and projects/now.md.
2. Ask only for what is missing: items, quantities, retail or wholesale, deadline.

## Do
3. Price each item from its product file (retail, or wholesale if 12+ pieces). If a cost is unknown, stop and say which.
4. Check stock. If short, say how many must be made and by when.
5. For a quote, draft the reply: items, unit price, total, lead time. No discounts unless I say so.

## File it
- Add the order or quote to the customer file (create it from customers/_template.md if new).
- Sales go to ledger.md only when paid.
- Update "Where I stopped" and "Next step" in projects/now.md.

## Never
- Invent facts, numbers or quotes. Unknown = "unknown".
- Write addresses or emails in any file.
