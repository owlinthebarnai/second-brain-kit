# products
- One file per product. Copy products/_template.md. Name: short-product-name.md.
- Stock lives only here. Update "Last counted" every time stock changes.
- Price = cost per piece x 3, rounded to the nearest 5. Wholesale = 60% of retail. If cost is unknown, price is unknown.
- Never write API keys, tokens or passwords in these files.
